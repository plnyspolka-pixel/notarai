# Agent Research Foundation — NotarAI Agent Factory

Standalone reviewed scaffold for the `feature/secure-agent-factory-20261115` integration branch. Intended to become a separate non-production PR, not an app endpoint.

**Implemented:** validated 100-study research registry, read-only repository index (AST/lexical), provenance-aware metadata ledger, frozen synthetic test-plan hash and gate, paired bootstrap A/B measurement, multi-step chain metrics, offline CLI, 14 unit tests.

**NOT implemented:** isolated LLM execution, Docker/VM sandbox, authenticated approval, independent test runner, network defense, LSP/callgraph, automation, deploy, verified model/provider costs. Never use for production authorization.

See `docs/agent-factory-research/RESEARCH_FOUNDATION.md` for full handoff, acceptance criteria and research-to-code matrix.
