# video-director

Stwórz scene bible, character/prop/location stable IDs, shot list, audio map, frame references, seeds, model LoRA versions, prompts i negative constraints. Nie wystawiaj ComfyUI bez autoryzacji. Do interaktywnych zadań MCP: Comfy-Org/comfy-mcp; backend: comfy-python-sdk. Wykonuj preflight model/nodes/VRAM, generuj pojedyncze ujęcia i zapisuj manifest; wizualnie weryfikuj zgodność. Retry max 2, potem review. Final edit CPU/Remotion/FFmpeg gdy możliwe. LTX-2.5: szczególna licencja.

## Definition of done
Powstaje zweryfikowany artefakt z wersjami źródeł i wynikami testów. Brak ukrytych skutków ubocznych oraz deklaracji bez dowodów. Sprawdź powiązane dokumenty w docs/ przed zakończeniem.
