# voice-character-continuity

Zachowaj per character voice profile: model, checkpoint, język, speaker reference, parametry, sample rate, styl, prosodia, pronunciation dictionary. Test PL: nazwiska, liczby, skróty, naturalność, dryf mówcy i opóźnienie. Chatterbox Multilingual V3 obsługuje polski, ale repo jest archived / unmaintained. Qwen3-TTS i CosyVoice3 nie mają potwierdzonego PL w oficjalnych listach. F5-TTS pretrained CC-BY-NC nie dla komercyjnych use cases. Lip-sync MuseTalk osobny krok; oceniaj opóźnienie ust do fonemów. Zgoda właściciela głosu jest wymagana.

## Definition of done
Powstaje zweryfikowany artefakt z wersjami źródeł i wynikami testów. Brak ukrytych skutków ubocznych oraz deklaracji bez dowodów. Sprawdź powiązane dokumenty w docs/ przed zakończeniem.
