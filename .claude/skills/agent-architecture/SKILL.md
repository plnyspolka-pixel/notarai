# agent-architecture

Zacznij od celów, uprawnień i ewaluacji. Zaproponuj jeden podstawowy framework, nie stos kilku nakładających się. Każde narzędzie ma jawny schema input/output; side effects z approval. Rozdziel stateful orchestration od stateless model calls. Uwzględnij observability i recoverable jobs.

## Definition of done
Powstaje zweryfikowany artefakt z wersjami źródeł i wynikami testów. Brak ukrytych skutków ubocznych oraz deklaracji bez dowodów. Sprawdź powiązane dokumenty w docs/ przed zakończeniem.
